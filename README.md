# Water Distillery 0.1

XML-мод для **Gnomoria**, добавляющий воду в рецепты напитков. Гномы наполняют вёдра в отдельном колодце, приносят их в Distillery и получают пустые вёдра обратно после приготовления.

> **Статус:** базовые рецепты и загрузка мира проверены пользователем в игре. Исправление прозрачности новых спрайтов требует подтверждения в игре.

## Возможности

| Объект | Назначение |
| --- | --- |
| **Brewing Well** | Отдельная мастерская для наполнения вёдер |
| **WaterBucket** | Ведро с водой — переносимый ингредиент |
| **Distillery** | Вино, пиво и чай дополнительно требуют воду |

### Рецепты

- **Brewing Well:** 1 пустое `Bucket` → 1 `WaterBucket`.
- **Distillery:** к исходным ингредиентам вина, пива и чая добавлено 1 `WaterBucket` на приготовление.
- Пустое `Bucket` возвращается как побочный продукт (`Byproduct`). Его материал берётся из второго ингредиента (`MaterialIndex = 1`).

Строительство Brewing Well требует **4 блока и 4 доски**. Для наполнения используется навык **Brewing**, для строительства — **Construction**. Рабочая клетка расположена рядом с колодцем: оставьте к ней свободный подход.

Обычный питьевой **Well** не изменён.

## Требования

- Копия Gnomoria с поддержкой XML-модов через папку `Mods`.
- Для безопасного тестирования — отдельная копия игры и новый мир.

**Gnoll, Visual Studio, C# и Python для игры не нужны.** Python с Pillow требуется только для запуска вспомогательного скрипта рисования.

## Установка

> Работайте с тестовой копией игры в «Документах». Файлы Steam-версии и обычные сохранения не изменяйте.

В подключённом проекте мод уже находится по адресу `Mods/WaterDistillery`; вручную копировать или распаковывать его не нужно.

Ожидаемая структура:

```text
Папка копии игры/
├── Gnomoria.exe
└── Mods/
    └── WaterDistillery/
        ├── settings.ini
        ├── README.md
        ├── Data/
        ├── Sprites/
        │   ├── default.png
        │   └── water-distillery.png
        └── tools/
            └── draw_sprites.py
```

1. Закройте игру, чтобы при следующем запуске она перечитала данные.
2. Запустите `Gnomoria.exe` из тестовой копии.
3. Создайте **новый тестовый мир**.
4. В **Advanced Options** выберите **Water Distillery 0.1** как основной мод.
5. Для первой проверки не подключайте другие моды.

Не переносите XML в `Content` и не заменяйте исходную папку `Mod Files`. Применение мода к существующим мирам не проверено.

## Использование

1. Изготовьте несколько пустых вёдер в **Carpenter**.
2. Постройте колодец через **Build → Workshop → Food/Drink → Brewing Well**.
3. Разрешите **Brewing** хотя бы одному гному.
4. Закажите в колодце `water bucket`. Работник принесёт пустое ведро и наполнит его.
5. На складе разрешите **goods → drink → water bucket**. Храните полные вёдра россыпью, без контейнеров.
6. В обычной **Distillery** закажите пиво, вино или чай.

Для небольшого запаса можно использовать заказ **Craft To**, например до 5 полных вёдер, если этот режим доступен в интерфейсе. Бесконечный **Repeat** может занять все пустые вёдра.

Без доступного полного ведра заказ напитка должен ждать ингредиент. Если включено автоматическое создание подзаказов, игра может заказать наполнение сама; специальная автоматизация в моде не реализована.

## Графика

Новые изображения определены в `Data/sprites.xml` и находятся в атласе `Sprites/water-distillery.png`.

| Изображение | Размер |
| --- | --- |
| Атлас | 128 × 32 пикселя |
| Каменное кольцо колодца | 32 × 32 пикселя |
| Деревянный ворот колодца | 32 × 32 пикселя |
| Полное ведро | 16 × 16 пикселей |

Колодец собран из двух совмещённых слоёв. Новые изображения не тонируются материалом, чтобы вода оставалась голубой. Оригинальный атлас игры не изменён.

Фон нового атласа приведён к образцу штатного `default.png`: **пурпурный RGB (255, 0, 255)** с непрозрачной альфой. Пурпурный фон при просмотре исходного PNG ожидаем; корректность его удаления игрой ещё нужно подтвердить.

`tools/draw_sprites.py` хранит способ рисования. `artwork-preview.png` и `transparency-check.png`, если присутствуют, служат только для просмотра и не используются как игровые текстуры.

## Ограничения

- Колодец — условный **бесконечный источник подземной воды**. Он не проверяет водоём и не расходует жидкость карты.
- `WaterBucket` — предмет-ингредиент, а не настоящий контейнер с жидкостью. Он не предназначен для непосредственного питья или поения животных.
- Возвращается новый экземпляр пустого ведра. Сохранение индивидуального качества, истории и износа исходного экземпляра не гарантируется.
- Одно ведро расходуется на одно приготовление независимо от реальных единиц объёма.
- Мод содержит полные переопределения отдельных XML-таблиц. Совместимость с другими модами, меняющими те же таблицы, не проверена.
- **Underground Works** уже включает водную механику этого мода. Для его тестирования выбирайте Underground Works отдельно, без одновременного подключения Water Distillery.

## Проверка мода

### Подтверждено

- Пользователь подтвердил работу базовых рецептов и загрузку мира после восстановления отсутствовавшей текстуры.
- Выполнены статические проверки XML, идентификаторов новых спрайтов, наличия текстур и границ прямоугольников.
- Проверено размещение `WaterBucket` в разделе склада `drink`.
- Пиксели фона нового атласа приведены к цветовому ключу оригинала; имитация удаления фона просмотрена.

### Требует игрового теста

- Прозрачность колодца и полного ведра после исправления фона.
- Отображение предметов при переносе и поворотах камеры.
- Материал пива, вина и возвращаемого пустого ведра.
- Отмена заказов, сохранение и повторная загрузка мира.

Игра в среде разработки не запускалась. Статические проверки не заменяют проверку на Windows.

## Диагностика

Если возникает ошибка, сохраните:

- точный текст ошибки и время последнего запуска;
- `gnomoria.log`, если он создан этим запуском;
- `Mods/WaterDistillery/log.txt`;
- описание этапа: загрузка мира, строительство, наполнение или приготовление.

При проблемах с графикой проверьте наличие `Sprites/water-distillery.png` и загрузку определений из `Data/sprites.xml` в журнале мода.

Ранее отсутствовавшая текстура восстановлена. Сам по себе стек вызовов `Camera.Update` не устанавливает причину вылета.

Не сохраняйте тестовый мир поверх обычного сохранения.

## Удаление

Закройте игру и удалите папку `Mods/WaterDistillery` из тестовой копии. **Не открывайте сохранения этого мода без него.** Исходные файлы игры модом не заменяются.
